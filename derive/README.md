# form_builder_derive

The derive macro of [form_builder](https://crates.io/crates/form_builder). Turn on its `derive` feature rather than
depending on this crate:

```bash
cargo add form_builder --features derive
```

The attributes are described in [Features: Derive](https://github.com/vertyll/form-builder/blob/main/docs/features.md#derive).
